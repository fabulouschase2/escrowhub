## Implementation Plan – Full MVP (Rust backend, React + Tailwind frontend, Solana Anchor escrow, LiveKit video, hCaptcha anti‑bot, Claude Vision AI analysis)

1. **Scaffold monorepo** with `/frontend` (Vite + React + Tailwind), `/backend` (Rust + Actix‑web), `/contracts` (Solana Anchor program) and a Docker‑Compose for local dev (PostgreSQL, LiveKit, Solana test validator).
2. **Auth & wallet**: email/password + optional Solana wallet connect, JWT issuance, protected routes.
3. **Deal & escrow API**: create deals, deposit stable‑coin escrow via Anchor `deposit_escrow`, store on‑chain tx signatures, fee calculation (10 %).
4. **Live video & screen‑share**: LiveKit room creation endpoint, React `LiveRoom` component with screen‑share, client‑side canvas blur for password fields, automatic recording storage.
5. **Dispute UI & AI analysis**: capture screenshots after session, upload to storage, invoke Claude Vision for milestone verification, admin dashboard to release/refund escrow.
6. **Anti‑bot**: hCaptcha on signup & deal creation, rate‑limit middleware, fingerprintjs device fingerprint, security headers.
7. **Deployment**: Frontend to Vercel, backend container to Railway/Render, Solana program to devnet then mainnet, CI pipeline with linting, testing, Docker build.
8. **Immediate actions**: create repo, run `cargo init`, `npm create vite`, `anchor init`, add Docker‑Compose, commit skeleton, then start auth implementation.
