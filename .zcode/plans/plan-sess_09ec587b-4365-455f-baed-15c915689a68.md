# Apple Glassmorphism Redesign & Full API Integration Plan

## 1. Visual Design Architecture: "Apple Glassmorphism" (Cupertino Dark / Frosted Glass)
- **Palette**:
  - **Background**: Deep Apple Black (`#000000`, `#0A0D14`, subtle mesh gradient with deep sapphire glow).
  - **Glass Surfaces**: `rgba(255, 255, 255, 0.05)` to `rgba(255, 255, 255, 0.12)` with backdrop blur (`backdrop-blur-xl` / `backdrop-blur-2xl`).
  - **Glass Borders**: Ultra-thin crisp borders (`border border-white/10` and `border-white/20` on hover).
  - **Accent & Highlights**: Apple Light Blue / Cyan (`#38BDF8`, `#0EA5E9`, `rgba(56, 189, 248, 0.2)` glow).
  - **Typography**: Clean SF Pro style sans-serif typography, high contrast crisp white text with muted secondary labels.
- **Glass Components**:
  - `GlassNavbar`: Floating pill / frosted glass header with brand logo, status indicator, Solana wallet badge, and logout.
  - `GlassCard`: Frosted container with specular edge reflections and soft ambient glow.
  - `GlassButton`: Primary Apple blue button (`bg-sky-500 hover:bg-sky-400 text-white shadow-lg shadow-sky-500/25`), secondary glass button (`bg-white/10 hover:bg-white/15 border border-white/10`).
  - `GlassInput`: Frosted translucent input field with focus ring in Apple light blue.
  - `GlassBadge`: Translucent pill indicators for statuses (`created`, `funded`, `active`, `completed`, `disputed`).

## 2. Full Endpoint & State Synchronization Integration
Ensure every single backend endpoint is actively wired and interactive in the UI:
1. **Auth & Wallet (`/auth/register`, `/auth/login`, `/health`)**:
   - Translucent login/register modal tabs with email/password and optional Solana Phantom / simulated wallet connect.
   - JWT token storage in `localStorage` and automatic header attachment in `api.ts`.
2. **Deals Management (`/deals`, `/deals/{id}`)**:
   - `DashboardPage`: Fetches live list of deals, shows real-time stats cards (Total Deals, Escrow Value, Active Sessions), quick action buttons.
   - `DealCreatePage`: Form to create a deal specifying seller wallet address, amount, currency, and platform fee with preview calculation.
3. **Solana Escrow Integration (`/escrow/deposit`, `/escrow/release/{id}`, `/escrow/refund/{id}`)**:
   - `LiveRoomPage` / Deal view: Trigger Solana contract mock transaction + store signature in backend via `/escrow/deposit`.
   - Release Escrow & Refund Escrow buttons connected directly to `/escrow/release` and `/escrow/refund`.
4. **Live Video & Screen-share (`/video/room`, `/video/room/{deal_id}`)**:
   - Screen-sharing simulator with blur canvas for credentials, LiveKit status panel, camera/mic controls with frosted icon buttons.
5. **Vision AI Analysis (`/ai/analyze`, `/ai/checks/{session_id}`)**:
   - Capture video snapshot or manual trigger -> `/ai/analyze` -> live AI milestone badge with confidence score display.
6. **Disputes (`/disputes`, `/disputes/{dispute_id}/resolve`, `/disputes/{deal_id}`)**:
   - `DisputePage`: Create dispute with evidence links, review ongoing disputes, resolve disputes with automatic escrow refund or release.

## 3. Backend Routing Wire-up
- Ensure `backend/src/main.rs` configures all route services (`auth`, `deals`, `escrow`, `video`, `ai`, `disputes`, `health`) so that every frontend API call succeeds against `http://localhost:8080`.

## 4. Verification & Testing
- Run `cargo check` in `escrowhub/backend` to verify all handlers compile.
- Run `npm run build` in `escrowhub/frontend` to verify strict TypeScript and Vite asset compilation.
